# Data sources and licenses

Every bundled text below is reproduced from the named open or public-domain edition. Translations
are kept as published; only markup, footnote markers and whitespace are cleaned. Transliteration
is either supplied by the source or generated by software and flagged `autoTranslit` in the data
(and “auto-transliterated” in the UI). Scripture text and translations are never generated,
paraphrased or altered.

If you believe a credit is wrong or a text should not be distributed here, open an issue and it
will be corrected or removed.

## Pipeline-supported but not bundled in this build

These have a working fetcher or a clear source path, and can be added with one command:

- **Sunan Abu Dawud, Jami‘ at-Tirmidhi, Sunan an-Nasa’i, Sunan Ibn Majah** — supported by
  `pipeline/fetch-hadith.mjs` and the same open dataset; run
  `node pipeline/fetch-hadith.mjs abudawud tirmidhi nasai ibnmajah`.

## Notes on quality and neutrality

- **Original languages.** Included wherever the open source provides them: Arabic, Hebrew, Greek,
  Sanskrit, Gurmukhi, classical Chinese. The Dhammapada’s Pali could not be matched automatically,
  so it is shown with the English translation only (the field is present but empty, never filled
  with invented text). The same applies to the Rig Veda, the Upanishads and the Yoga Sutras: the
  public-domain editions used here print the English alone, so no Sanskrit is shown rather than
  attach a text from a different edition.
- **Auto-transliteration.** Hebrew and Greek in the Bible, Arabic hadith, and Tanakh Hebrew are
  romanised by the pipeline and flagged. The romaniser is deterministic and not authoritative.
- **Verse numbering.** Each edition keeps its own numbering. Hebrew Tanakh numbering differs from
  Christian Bible numbering in a few books (for example Joel); references are shown exactly as the
  source gives them.
- **Search scope.** The prebuilt index covers the English translation, the transliteration and the
  theme tags. Original-language text is shown in the reader and is not part of the search index.
- **Tags.** Themes are derived from the editable `data/synonyms.json` map, not from the source
  editions. They are metadata, not scripture.
